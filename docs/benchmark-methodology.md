# Benchmark methodology

## Focused 60

The additional benchmark contains six groups of ten:

1. Responsibility and deadline field integrity
2. Provenance and staleness
3. Medication instruction conflict
4. Consent and privacy
5. Caregiver capacity and delegation
6. Closed-loop workflow and failure

The runner asserts exactly 60 cases, executes them consecutively, retains failures, and writes readable and JSON evidence.

## Burden-reduction benchmark

No time-saved result has been measured.

A Phase 2 within-participant protocol will compare:

- manual document review, task identification, deadline discovery, conflict finding, assignment, question preparation, and tracking;
- the same case using HEARTH, including setup, review, corrections, and approvals.

Record:

- start and stop time by workflow segment;
- missed responsibilities and conflicts;
- incorrect owners or deadlines;
- correction count and duration;
- external actions and outcomes;
- user actions required;
- completion rate;
- net time difference;
- perceived effort and trust;
- accessibility barriers.

Counterbalance workflow order, use locked equivalent cases, preserve failed runs, and distinguish setup time from recurring use. Analyze medians and distributions; do not generalize a small pilot as population effectiveness.
