# Contrast matrix

The final audit measured representative production tokens using WCAG 2.2 AA thresholds: 4.5:1 for normal text and 3:1 for non-text interface components.

| Pair | Ratio | Threshold | Result |
|---|---:|---:|---|
| Ink on paper | 13.81:1 | 4.5:1 | Pass |
| Muted on paper | 4.67:1 | 4.5:1 | Pass |
| Faint on white | 5.08:1 | 4.5:1 | Pass |
| White on pine | 11.71:1 | 4.5:1 | Pass |
| Pine on white | 11.71:1 | 4.5:1 | Pass |
| Focus amber on paper | 5.29:1 | 3:1 | Pass |

An initial audit exposed three serious sidebar contrast failures. The sidebar text tokens were corrected and the final rerun reported zero axe violations across the welcome, reviewer-demo, and burden-study states.
